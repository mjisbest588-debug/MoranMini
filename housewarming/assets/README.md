# MoranMini HOUSE 이미지 · 음원

파일을 같은 이름으로 교체하면 초대장에 바로 반영됩니다.
이미지 경로, 날짜/시간, 주소, 메뉴, 안내 문구, 배경음악 경로는 `housewarming/js/config.js`의 `MORANMINI`에서만 관리합니다.

| 파일 | 쓰임 |
|------|------|
| `tshirt-1.png` | 메인 화면 왼쪽 티셔츠 (투명 배경) |
| `tshirt-2.png` | 메인 화면 오른쪽 티셔츠 (투명 배경) |
| `door-before.png` | 문 열기 직전 / 초대장 집 일러스트 (투명 배경) |
| `doorbell-new.mp3` | 업로드 원본 초인종 효과음 |
| `doorbell.mp3` | 초인종 띵동 효과음 (doorbell-new 기준) |
| `door-open-new.mp3` | 업로드 원본 문 열림 효과음 |
| `door-open.mp3` | 문 열림 효과음 (door-open-new 기준) |
| `러브하우스 브금 - KER FLU.mp3` | 업로드 원본 배경음악 (보존) |
| `러브하우스 브금 - KER FLU-trimmed.mp3` | 앞 1초 제거 BGM (웹 재생용) |
| `qr-moranmini-house.png` | 집들이 QR ( `/m` → 초대장 ) |
| `source/` | 누끼 전 원본. 다시 처리할 때만 사용 |
